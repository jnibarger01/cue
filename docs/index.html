Run Cue locally

Transcript retrieval runs through Cue’s Flask server. With Git and uv installed, run these commands in Bash or Zsh.

git clone https://github.com/jnibarger01/cue.git
cd cue
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
python app.py

Once Flask starts, open Cue on your computer.
